GATHER - LOCAL REAL-TIME CHAT

Requirements: Node.js 22.13 or newer and npm.

From the project root:
  npm install
  npm run dev

Open http://localhost:5173 during development. Vite proxies /api and
/socket.io to Express on port 3001.

Other root commands:
  npm run build       Build React and compile the TypeScript backend.
  npm run start       Start the built app at http://localhost:3001.
  npm run typecheck   Check TypeScript in both workspaces.
  npm test            Run backend integration tests.

For another device on the same network, open the host computer's LAN IP address
instead of localhost. Share links use the address shown in the browser. In dev
mode use port 5173; after build and start use port 3001. The firewall must allow
the chosen port.

The database is stored at backend/data/chat.sqlite and is created automatically.
To use another path, set DATABASE_PATH before starting the backend. PORT defaults
to 3001 and HOST defaults to 0.0.0.0.

Guests do not have passwords. A browser keeps its guest ID and alias in local
storage. Anyone with a room link can join and read that room's recent messages.
